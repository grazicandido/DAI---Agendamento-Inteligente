# DAI---Agendamento-Inteligente
Propomos um Agente de IA omnichannel que atua em tempo real via WhatsApp, App, Site e Telefone para eliminar as fricções da jornada de agendamento, desde a intenção até o comparecimento. A solução foca em ser proativa, empática e resolutiva, garantindo que o paciente não desista do processo.
